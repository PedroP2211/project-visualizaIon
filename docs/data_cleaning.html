Limpieza y preparación de datos

Author

Pedro Pena - Juan Endara

Introducción

En este documento se presenta el proceso de limpieza y preparación de datos realizado sobre el dataset de ventas de Corporación La Favorita.
El objetivo es dejar los datos listos para el análisis exploratorio y la construcción de visualizaciones posteriores.

1. Carga de librerías y dataset

Code 
import pandas as pd
import numpy as np

En esta etapa se cargaron los tres archivos principales del proyecto. El archivo train.csv contiene la información de ventas, que será la base principal del análisis. El archivo stores.csv aporta atributos de las tiendas, como ciudad, estado, tipo y clúster. Por su parte, transactions.csv incluye el número de transacciones diarias por tienda, lo cual puede ser útil para contrastar el comportamiento de las ventas.

La carga inicial permite verificar que los archivos se leen correctamente y observar una primera muestra de su contenido.

Verificación de valores faltantes

La revisión de valores faltantes es una etapa fundamental en la preparación de datos, ya que permite detectar información incompleta que podría afectar el análisis o generar errores en las visualizaciones.

En este caso, se evaluó tanto la cantidad como el porcentaje de valores nulos por columna en los tres datasets, con el fin de determinar si era necesario aplicar imputaciones, eliminar registros o mantener la información tal como se encuentra.

Transformaciones de variables

Una de las transformaciones principales del proceso de preparación consistió en convertir la variable date al tipo de dato fecha. Esta decisión fue necesaria porque inicialmente la variable se encontraba en formato texto, lo que limita el análisis temporal.

Transformar esta columna permite agrupar datos por día, mes o año, además de generar nuevas variables derivadas que facilitan la construcción de visualizaciones y el análisis de patrones estacionales.

Code 
# Convertir la columna date a formato datetime
df["date"] = pd.to_datetime(df["date"])

# Verificar cambio
df.info()

# Crear variables derivadas de la fecha
df["year"] = df["date"].dt.year
df["month"] = df["date"].dt.month
df["day"] = df["date"].dt.day
df["day_of_week"] = df["date"].dt.day_name()
df["week"] = df["date"].dt.isocalendar().week.astype(int)

A partir de la variable date se generaron nuevas variables temporales: year, month, day, day_of_week y week. Estas variables fueron creadas para facilitar el análisis de tendencias de ventas en distintas escalas de tiempo y para apoyar visualizaciones como series temporales, comparaciones mensuales y patrones por día de la semana.

La generación de estas variables constituye una decisión de transformación importante, ya que amplía las posibilidades analíticas sin alterar la información original del dataset.

Revisión de valores inconsistentes

Además de los valores faltantes, se revisaron posibles inconsistencias en variables numéricas clave. En particular, se evaluó si existían ventas negativas o promociones negativas, ya que estos casos podrían reflejar errores de registro o problemas en la captura de datos.

La detección de este tipo de valores ayuda a validar la coherencia del dataset antes de realizar análisis agregados o comparativos.

Code 
# Verificar ventas negativas
(df["sales"] < 0).sum()
np.int64(0)
Code 
# Verificar promociones negativas
(df["onpromotion"] < 0).sum()
np.int64(0)

La revisión de inconsistencias permitió validar la calidad de las variables sales y onpromotion. En caso de no encontrarse valores negativos, se puede considerar que los datos presentan coherencia básica para el análisis. Si llegaran a existir, estos registros deberían ser evaluados individualmente antes de decidir su eliminación o corrección.
